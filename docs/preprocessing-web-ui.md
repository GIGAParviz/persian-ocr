# آزمون پردازش تصویر در پایپلاین اصلی

از صفحهٔ http://127.0.0.1:8000/app، حالت «پردازش تصویر» را پیش از آپلود انتخاب کنید. هر فایلِ واردشده حالت انتخاب‌شده در زمان آپلود را نگه می‌دارد. کنار خروجی OCR، دکمهٔ جابه‌جایی بین «تصویر اصلی» و «تصویر ورودی مدل پس از پردازش» دیده می‌شود.

| حالت | کار انجام‌شده پیش از Indra |
|---|---|
| تصویر اصلی | بدون پردازش سراسری؛ بازخوانی محدود مبلغ کم‌رنگ در شرایط مشخص همچنان بخشی از پایپلاین است. |
| شارپ‌سازی ملایم | ترکیب تصویر خاکستری با نسخهٔ تار آن، با وزن ۱۵٪. |
| شارپ + نور ملایم | شارپ‌سازی و سپس ترکیب ۱۵٪ از اصلاح نور. |
| شارپ + اتصال شکستگی | شارپ‌سازی و اتصال شکستگی‌های نزدیک به یک پیکسل با وزن ۲۵٪. |
| شارپ + اتصال + نور ملایم | سه مرحلهٔ قبلی به همین ترتیب. |

مقدار انتخاب‌شده در فیلد preprocess خروجی JSON هم ثبت می‌شود تا فایل‌های آزمون با هم اشتباه نشوند.

همهٔ حالت‌ها در persian_ocr/vision/preprocess.py اجرا می‌شوند و از همان process_document در CLI، API و Web UI عبور می‌کنند. حالت پیش‌فرض «تصویر اصلی» است. حذف هافتون با فرکانس ثابت و حذف مهر رنگی جزو این حالت‌ها نیستند؛ آزمایش‌های قبلی برای آن‌ها افزایش دقت سراسری نشان ندادند و بعضی مبالغ را تغییر دادند.

## نتیجهٔ کنترل عددی

سه عکس با مبلغِ تأییدشده از مسیر اصلی و مدل Indra اجرا شدند:

| عکس | تصویر اصلی | حالت‌های پردازشی |
|---|---|---|
| فاکتور داروخانه | 3,192,200 باقی ماند. | شارپ‌سازی تنها آن را حفظ کرد؛ نور ملایم یا اتصال شکستگی آن را از خروجی حذف کرد. |
| رسید | 25,000,000 باقی ماند. | این مبلغ در هر چهار حالت پردازشی باقی ماند. |
| برگهٔ آزمایشگاه | 11,100,000 با بازخوانی محدود بازیابی شد. | در هر چهار حالت پردازشی این مبلغ بازیابی نشد. |

بنابراین حالت‌های پردازشی برای مقایسه و مشاهده هستند و انتخاب آن‌ها در UI با هشدار همراه است. وجود تصویر پردازش‌شده در UI به معنی دقیق‌ترشدن OCR نیست؛ هر مبلغ باید با تصویر اصلی سنجیده شود. محاسبهٔ تصویر این حالت‌ها با خروجی آزمایش قبلی در سطح پیکسل یکسان بررسی شد.

## اجرای محلی

    .\.venv\Scripts\python.exe -m persian_ocr serve --host 127.0.0.1 --port 8000

برای CLI، گزینهٔ --preprocess مقدارهای original، sharpen، sharpen_light، connect و soft_light را می‌پذیرد. endpointهای /ocr و /app/run نیز همین مقدارها را در پارامتر query به نام preprocess می‌گیرند.
