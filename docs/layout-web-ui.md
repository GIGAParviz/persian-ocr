# نمایش چیدمان صفحه در Web UI

در `/app` پس از پردازش تصویر، نمای پیش‌فرض «چیدمان متن در صفحه» است. هر خط و سلول جدول با مختصات باکس OCR روی بومی هم‌اندازهٔ تصویر ورودی مدل قرار می‌گیرد. کنار آن، تصویر مبنای OCR نشان داده می‌شود. دکمهٔ «نمایش تصویر اصلی» تفاوت تصویر اصلی و تصویر ورودی مدل را نشان می‌دهد.

- «نمای متن پیوسته» خروجی متنی پیشین را برای خواندن خطی و مقایسه باز می‌کند.
- «بزرگ‌نمایی چیدمان» اندازهٔ نمایش صفحهٔ بازسازی‌شده را تغییر می‌دهد؛ مختصات اصلی ثابت می‌مانند.
- «کپی متن صفحه» متن پیوستهٔ پردازش‌شده را کپی می‌کند، حتی وقتی نمای چیدمان فعال است.
- `txt` متن پیوسته، `json` متن و مختصات `layout` هر صفحه، و «دانلود چیدمان HTML» صفحهٔ فعلی را با متن‌های مکان‌دار ذخیره می‌کند.

چیدمان بازسازی تقریبی از باکس‌های تشخیص‌داده‌شده است. اگر مدل متنی را نخواند یا باکس، جهت صفحه یا مرز جدول را اشتباه تشخیص دهد، آن بخش در خروجی HTML نیز دقیق نخواهد بود. مهر، تصویر و رنگ‌های سند بازسازی نمی‌شوند. برای کنترل جای متن، نمای چیدمان را کنار تصویر مبنای OCR بررسی کنید.

پاسخ `/app/run` برای هر صفحه `layout.size`، `layout.items`، `layout.cells` و `layout.tables` را برمی‌گرداند. هر item شامل `box`، `text`، `conf` و `source` است. باکس‌ها در مختصات تصویر واقعی ورودی مدل‌اند؛ تصویر JPEG پیش‌نمایش ممکن است برای انتقال کوچک شده باشد.
